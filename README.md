# hack_battle
💻 スート・コード：ネットワーク [経済影響拡張版]
サイバーパンク・ハッキングバトル — 資金（Credits）が勝負の鍵を握る、新感覚のローグライク・ポーカー風カードゲームです！

🌟 概要
プレイヤーはハッカーとなり、サイバー空間で敵のAIとリアルタイムに攻防を繰り広げます。
トランプの通常カード（4スート）に加えて特殊カード（バグ・AI）を駆使し、手札から最大5枚を同時に選択して強力なポーカー役を発動させます。

さらに本作の最大の特徴である「経済影響拡張版」システムにより、所有する暗号資産（Credits）の多さが全カードの効果や役の倍率を増幅させます。ただ攻撃するだけでなく、資金調達とリソース管理のバランスが勝利の命運を分けます。

🎮 主な特徴・ゲームシステム
🧠 最大5枚の同時選択コンボ

手札から最大5枚のプロトコル（カード）を選択し、一斉に実行。

🔥 ポーカー役による強力なバフ

ストレートフラッシュ、フォーカード、スリーカード、フラッシュ、ペアなどの役が成立すると、ダメージや効果が劇的に跳ね上がります。

📈 経済スケーリング（Credits拡張）

資金（Credits）が多いほど、カードの効果や役の倍率に補正（スケーリング）がかかります。稼げば稼ぐほど攻撃力が爆発的にアップ！

🤖 思考するCPUAI

CPU側も手札の組み合わせから最適な5枚を選び、戦況に応じて攻撃・回復・資金調達を高度に判断してプレイヤーに襲いかかります。

🛠️ 使用技術
Python

Streamlit（インタラクティブWebアプリUI）

🚀 遊び方（ローカル実行手順）
リポジトリをクローンまたはダウンロードします。

必要なライブラリ（Streamlit）をインストールします。

Bash
pip install streamlit
アプリを起動します。

Bash
streamlit run app.py
ブラウザが自動で起動し、ハッキングバトルが始まります！

📜 ルール・カード属性
♣ クラブ: ウイルス攻撃（敵のサーバー耐久を削る）

♠・♥ スペード / ハート: システム修復（自機のHPを回復）

♦ ダイヤ: 暗号資産調達（資金（Credits）を増やして次のターンを優位にする）

🌟 バグカード / 🤖 AIカード: 予測不能な効果や特殊な強襲を引き起こす特殊プロトコル
